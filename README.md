# DIM013 Project

A Python project demonstrating Git workflows, virtual environments, and coding best practices.

## Features

- Load CSV files using pandas
- Handle UTF-8 BOM encoding
- Explicitly specify CSV separators
- Practice Git branching and merge conflict resolution

## Project Structure

- `src/`: Python source code
- `data/`: Sample CSV dataset
- `tests/`: Automated tests
- `requirements.txt`: Python dependencies

## Usage

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the CSV loader:

```bash
python src/load_data.py data/sample.csv
```
